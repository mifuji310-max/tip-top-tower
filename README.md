# Tip Top Tower

ブロックを積んで、空のてっぺんへ。スマホのブラウザで遊べる3Dブロック積みミニゲームです。

**遊ぶ：https://mifuji310-max.github.io/tip-top-tower/**

## 遊び方

- 動いているブロックをタップして、下のブロックに重ねます。はみ出した分は切れて落ち、全部はずすとミス。
- ぴったり重ねると **PERFECT**。続けると音がドレミと上がります。4回続けると「お守り」（ミスを1回助けてくれる）。
- 1段＝10m。東京タワーやスカイツリーなど、本物の建物の高さを超えていきます。窓の数＝住人の数で、太いまま高く積むほど住人がふえます。
- **ENDLESS**：60秒＋PERFECTで時間がのびる記録チャレンジ（最大3分）。
- **STAGE**：建物の高さまで積めばクリア。ブロックは1往復するまでに置きます。
- 特殊ブロック（ロケット・氷・ふくらむ・磁石・ワープ・おばけ・雷・ミニ）や風、20種類の色のテーマ、22種類のバッジがあります。くわしくはゲーム内の **RULES** を見てください。
- キーボード：Space／Enter＝置く・スタート、R＝やり直し、C／←→＝視点変更。

## ホーム画面に追加する

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）

一度開いたあとは、ネットにつながらない場所でも起動できます。

## 技術

- HTML / CSS / JavaScript の1ファイル（`index.html`）。外部ライブラリなし。
- 3D表示は WebGL を直接使用。WebGL が使えない環境では Canvas 2D で同じ3D座標を描く代わりの描画に切り替わります。
- 音は Web Audio API で、その場で合成しています。
- 記録・バッジ・ステージの★はブラウザ（localStorage）に保存。サーバーは使いません。
- オフライン起動はサービスワーカー（`sw.js`、ネット優先）。
